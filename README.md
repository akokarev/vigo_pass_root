# VIGO / Qualcomm Password Calculator

Локальный статический калькулятор, перенесённый из исходного `vigo_pass(root).cmd`.

## Важно

Этот проект предназначен для **авторизованного администрирования собственных/обслуживаемых устройств**. Любые действия вы делаете на свой страх и риск!

## Алгоритм

- PASS 1: PDSN смешивается посимвольно с `E13S31NMP5DfCs24`, затем дважды SHA-256; берутся первые 8 hex-символов второго хэша: `DfCs` + 8 символов + `#!`.
- PASS 2: `DfCs` + последние 4 символа `persist.radio.sn` + `#!`.
- PASS 3: `DfCs0715#!`.

Исходный `.cmd` сохранён для аудита в `vigo_pass(root).cmd`.
