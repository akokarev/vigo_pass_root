# VIGO / Qualcomm Password Calculator

Статический калькулятор паролей VIGO с поддержкой **PWA (Progressive Web App)**.

## Возможности

- расчёт PASS 1 и PASS 3 сразу после ввода PDSN;
- расчёт PASS 2 после ввода `persist.radio.sn`;
- работа полностью offline после первого открытия/установки;
- установка на Android/iOS как отдельного приложения;
- на Android/Chromium доступна собственная кнопка установки;
- при запуске уже установленного приложения в режиме `standalone` вместо «Установить приложение» показывается **«Обновить»**;
- обновление проверяется относительно того же сайта, с которого запущено приложение — жёстко заданного домена в коде нет.

## Как работает PWA

`manifest.json` задаёт имя, иконки и режим `standalone`. `sw.js` кэширует необходимые файлы и использует стратегию network-first: при наличии интернета приложение получает свежие файлы, а без интернета использует последнюю рабочую копию.

Кнопка **«Обновить»** обращается к `./version.json` относительно текущего URL. Поэтому, например, при запуске с `https://vigo.kokarev.su/` обновления берутся с `https://vigo.kokarev.su/`; менять адрес в JavaScript не требуется.

При выпуске новой версии необходимо изменить номер версии одновременно в:

- `version.json`;
- `app.js` (`CURRENT_APP_VERSION`);
- `sw.js` (`CACHE_NAME`).

После публикации новой версии установленное приложение обнаружит отличие и перезагрузит свежие файлы.

## HTTPS

Для установки PWA сайт должен работать через HTTPS (либо localhost при разработке). GitHub Pages и `https://vigo.kokarev.su/` подходят для этого сценария.

## iOS

iOS не предоставляет веб-страницам универсальный программный аналог Android `beforeinstallprompt`. Поэтому кнопка показывает пользователю инструкцию: **Поделиться → На экран Домой**. После установки PWA запускается в отдельном окне.

## Локальный запуск

```powershell
python -m http.server 8080
```

Открыть `http://localhost:8080/`.
